# Tasca S1.02 - PHP Basics

Descripció: Exercicis introductoris de PHP per treballar variables, strings, operacions matemàtiques, condicionals i funcions.

## Tecnologies

* PHP
* XAMPP
* Visual Studio Code

## Instal·lació

1. Clonar el repositori:

```
git clone https://github.com/jordiartigues/Tasca-S1.02.git
```

2. Obrir el projecte amb Visual Studio Code.

3. Per executar els exercicis des de la terminal, entrar a la carpeta del projecte:

```
cd Tasca-S1.02
```

4. Entrar a la carpeta dels exercicis:

```
cd nivell-1
```

5. Executar l'exercici:

```
php exercici1.php
```

6. Els exercicis que utilitzen `readline()` s'han d'executar des de la terminal.

## Estructura del projecte

```
Tasca-S1.02/

    ├── exercici1.php
```
